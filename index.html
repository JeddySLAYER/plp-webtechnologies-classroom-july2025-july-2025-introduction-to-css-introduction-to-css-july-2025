Understanding the Box Model

Every element on a web page is considered a rectangular box. The Box Model defines how these boxes are sized and spaced using:

  • Content – the actual text or image within the box
  • Padding – space between content and the border
  • Border – outlines the element
  • Margin – space outside the border, separating boxes
